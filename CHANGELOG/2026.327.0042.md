# 2026.327.0042 — fix(ai-toolkit): give the skill file its frontmatter and drop the node's inline copy

## Summary

The `ai-toolkit` skill file had **no frontmatter at all**, while its routing node carried
an inline `description:`. The marketplace generator therefore refused the corpus:

```console

```

(`name`/`family`/`owner`), per the skill contract: the file is the body, the node routes.
